# Loan Approval Prediction System

## Overview
This project predicts whether a loan application will be approved using Machine Learning.

## Features
- Loan prediction using ML
- User-friendly UI
- Fast prediction results
- Data preprocessing

## Technologies Used
- Python
- Flask
- Machine Learning
- HTML/CSS
- Pandas
- Scikit-learn
